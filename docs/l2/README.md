# L2 — Optional advanced tracks

L2 is **optional growth**. It is not how you start, and it is not a second product.

**L0 and L1 are the product today:** a terminal you open on purpose, Claude Code in the
project folder, and a harness that can say *no*. If that path is not boring in a good
way yet, stay there. Read the [novice guide](../novice-guide.md) and install
[`setup-harness`](../../skills/setup-harness/).

## When to stay on L0 / L1

Stay on L0/L1 if any of these are true:

- You do not yet open a terminal, `cd` into the job folder, and run `claude` there
- You do not have a short `CLAUDE.md` plus at least one check that can fail
- You are still collecting tools, rules, or a “Second Brain” instead of finishing one folder
- You want L2 because a thread said you *must* add Cursor / OpenCode / Hermes to be serious

Complexity is not the door to getting started. A folder you own plus rails that can
stop the agent is enough.

## When L2 helps

Add **one** L2 track after L0/L1 feel solid — when the basics are muscle memory and a
specific gap shows up:

| Gap | Track |
|---|---|
| Multi-file review, PRs, or a cloud agent on the same repo | [Cursor](./cursor.md) |
| A second terminal agent, or a non-Anthropic model path | [OpenCode](./opencode.md) |
| Occasional background / unattended help — never the everyday path | [Hermes](./hermes.md) |

Do not stack all three. Do not replace Claude Code + harness. The new tool sits
**alongside** the rails; it does not become the rails.

## Tracks

1. [Cursor](./cursor.md) — IDE + agents beside Claude Code
2. [OpenCode](./opencode.md) — open-source terminal agent
3. [Hermes](./hermes.md) — autonomous agent with a learning loop

Each page covers who it is for, prerequisites, a short “keep it lean” section, and
what not to do.

## Keep this library small

These pages are field notes, not a course. Official install and auth steps live
upstream and change — follow the vendor docs for those, and keep skipr’s rule:
**fewer skills, more checks.**
