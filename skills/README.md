# Skills (public)

Lean Claude Code skills shipped with skipr. Read them on GitHub; install a copy under
`~/.claude/skills/<name>/` on your machine.

| Skill | Purpose |
|---|---|
| [`setup-harness`](./setup-harness/) | Minimal folder harness: short `CLAUDE.md` + checks that can fail |
| [`fdd`](./fdd/) | Fast Driven Development: short note, slices, a preview to review the build |

Beginner path and levels: [`docs/novice-guide.md`](../docs/novice-guide.md).
